# EvoAssist для Minecraft 26.2

Клиентский Fabric-мод для DiamondWorld Prison Evo.

## Требования

- Minecraft 26.2
- Fabric Loader 0.19.5 или новее
- Fabric API для Minecraft 26.2
- [EvoPlus](https://modrinth.com/mod/evoplus) 3.3.2 или новее, совместимый с Minecraft 26.2
- Fabric Language Kotlin 1.13.13 или новее (зависимость EvoPlus)
- Java 25

## Установка

Скопируйте `EvoAssist-v1.1.0.jar`, EvoPlus, Fabric API и Fabric Language Kotlin в папку `mods` вашей игры. Запустите Minecraft с профилем Fabric 26.2. Для работы EvoAssist требуется EvoPlus; копия API в EvoAssist не встраивается.

Нажмите **правый Ctrl**, чтобы открыть настройки, либо используйте **/ea**. Другую клавишу для открытия меню можно назначить во вкладке Интерфейс > Настройки меню, используя такую же систему привязки клавиш, как в настройках управления Minecraft. Доступные вкладки: Боссы, Киллы, Шахта, Цели Добычи, Клан, Цели Клана, Калькулятор и Интерфейс. Русский и английский языки автоматически выбираются в зависимости от языка Minecraft, а для остальных языков используется английский.

Команды: `/evoassist` или `/ea` для открытия настроек, а команды `/evoassistwidgets` или `/eaw` для открытия настроек виджетов EvoAssist в EvoPlus.

Настройки виджетов доступны в меню аддона EvoAssist в EvoPlus и по команде `/eaw`. Здесь можно включать и выключать виджеты. Их расположение и масштаб настраиваются в общем редакторе виджетов EvoPlus; добавить виджет можно из его боковой панели. Отрисовка текста и иконок выполняется через API EvoPlus, поэтому они перемещаются и масштабируются вместе.

При переходе на 1.1.0 все виджеты EvoAssist однократно отключаются, включая панель вкладок чата. Добавьте нужные виджеты из боковой панели редактора EvoPlus и настройте их расположение и масштаб. Далее видимость, положение и масштаб сохраняет EvoPlus; при следующих запусках выбранные виджеты остаются включёнными. Все 13 виджетов доступны в семи категориях: Шахта, Цели Добычи, Боссы, Киллы, Клан, Цели Клана и Чат. Для целей без заданного значения в редакторе показывается пример; во время игры они скрыты.

Настройка целей, сброс статистики, привязка клавиши меню и вкладки чата остаются в меню EvoAssist. Панель вкладок чата тоже перемещается и масштабируется в редакторе EvoPlus; ориентация панели настраивается во вкладке Интерфейс EvoAssist. Она отображается при открытом чате, а в редакторе доступен её пример. Видимость панели сохраняет EvoPlus.

Под полем каждой цели находится отдельная карточка сброса с подтверждением: она обнуляет значение этой цели и её прогресс. Кнопка сброса всех целей обнуляет только прогресс, сохраняя значения целей.

Цели Добычи позволяет отдельно задавать цели по количеству блоков, активному времени, деньгам и шардам. Цели Клана содержит отдельные цели по очкам, золоту и опыту клана. После выполнения цель фиксируется до её сброса или замены. Для числовых целей поддерживаются десятичные сокращения, например `5.32B` или `5.32K`. Максимальное значение для денег и шардов составляет `999Q`, для клановых целей — `1M`, а для времени — 9999 минут. Эти ограничения применяются автоматически и не отображаются в подсказках полей ввода. Уведомления о выполнении целей показывает EvoPlus. Их включение для добычи и клана настраивается отдельно в EvoAssist; общая продолжительность — от 1 до 60 секунд. Статистика целей сохраняется после переподключения и перезапуска игры.

Общая статистика добычи сохраняется отдельно для каждого сервера и остаётся после переподключения и перезапуска игры, пока вы вручную не сбросите её в меню мода. Расчёт добычи в час основывается на недавней активности и постепенно снижается до нуля, если вы перестаёте добывать блоки.

Для боссов доступны два виджета EvoPlus: деньги и шарды, а также обычные, адские и энд жетоны из сообщений о наградах за боссов и данжей. Клановый виджет показывает очки, опыт и золото клана. Вкладки Боссы и Клан в EvoAssist содержат кнопки сброса соответствующей статистики.

Для отображения денег используются сокращения K, M, B, T и Q с точностью до двух знаков после запятой. Остальные награды отображаются целыми числами. Награды сразу сохраняются в `config/evoassist_rewards.properties` отдельно для каждого адреса сервера и сохраняются после переподключения и перезапуска игры до ручного сброса.

Fabric ID мода — `evoassist`. Конфигурация сохраняется в `config/evoassist.jsonc`, а цели добычи — в `config/evoassist_mining_goals.properties`. Изменение ID означает, что мод начинает работу с новыми настройками и статистикой вместо загрузки файлов, ранее созданных под ID `evo_assist`.

Вкладка **Калькулятор** под Целями Клана рассчитывает стоимость переходов между указанными уровнями по встроенной таблице до 600 уровня. Результат обновляется при вводе данных: деньги сокращаются, например `43.55T`, а блоки отображаются полностью, например `3 120 000`. Количество блоков — общий порог целевого уровня, как в исходном калькуляторе, а не разница порогов. Уровень 1 имеет нулевую базу; таблица содержит значения для уровней 2–600.

По умолчанию выбрано **Без скидки**. Варианты зависят от целевого уровня: с 482 доступны 5% и 10%, с 541 добавляются 15% и 20%. Выберите скидку, которая действительно куплена: мод не определяет её автоматически. Скидки 5% и 10% действуют на стоимость переходов начиная с уровня 482, а 15% и 20% — с 541. Блоки скидка не изменяет. Введённые уровни, выбранная скидка и режим сохраняются в настройках. Над полями уровней находится выбор режима Evo или Evo Fast. В Evo Fast общий порог блоков делится на 1,5 с округлением вверх до целого блока; стоимость в деньгах совпадает с Evo.

Вкладка **Киллы** под Боссами содержит карточку сброса с подтверждением. Количество убийств отображается в виджете EvoPlus. Учитываются серверные сообщения вида `Вы убили игрока Heavencon24 и получили 18.62M$`, пришедшие после установки обновления. Счётчик сохраняется в `config/evoassist_rewards.properties` отдельно для каждого сервера; сброс киллов сохраняет остальные награды. Деньги из сообщения о килле не добавляются к наградам с боссов. Виджет **Киллов** с иконкой алмазного меча доступен в категории Киллы в EvoPlus; включение, положение и масштаб настраиваются там.

## Разработка

Интеграция использует `compileOnly` API EvoPlus 1.2.0, совместимый с EvoPlus 3.3.2. `runClient` подключает EvoPlus и Fabric Language Kotlin как зависимости среды разработки. `gradlew build` проверяет статистику, цели, калькулятор, распознавание киллов, локализацию, вкладки чата и контракт регистрации/отрисовки виджетов EvoPlus.
