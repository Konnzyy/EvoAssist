# EvoAssist для Minecraft 26.2

Клиентский Fabric-мод для DiamondWorld Prison Evo. Текущая версия — **1.2.0**.

## Требования

- Minecraft 26.2
- Fabric Loader 0.19.5 или новее
- Fabric API для Minecraft 26.2
- [EvoPlus](https://modrinth.com/mod/evoplus) 3.3.4 или новее, совместимый с Minecraft 26.2
- Fabric Language Kotlin (зависимость EvoPlus)
- Java 25

## Установка и настройки

Скопируйте `EvoAssist-1.2.0.jar`, EvoPlus, Fabric API и Fabric Language Kotlin в папку `mods`. Запустите Minecraft с профилем Fabric 26.2.

Все настройки EvoAssist открываются в меню аддона EvoPlus. Нажмите **правый Ctrl** либо используйте `/ea`, `/evoassist`, `/eaw` или `/evoassistwidgets`. Кнопка настроек в Mod Menu открывает то же меню. Клавишу можно переназначить в категории **Интерфейс** аддона или в настройках управления Minecraft.

Категории аддона: **Шахта**, **Цели Добычи**, **Боссы**, **Киллы**, **Клан**, **Цели Клана**, **Цели Рыбалки**, **Интерфейс**. Русский и английский языки выбираются по языку Minecraft. Для остальных языков используется английский.

## Виджеты

Все 14 виджетов зарегистрированы в EvoPlus: статистика добычи, цели по блокам, времени, деньгам и шардам, награды и жетоны боссов, киллы, клановая статистика, три клановые цели, цель рыбалки и вкладки чата.

Включайте нужные виджеты в настройках аддона или добавляйте из боковой панели общего редактора EvoPlus. Там же настраиваются расположение, масштаб и фон. Отрисовка текста и иконок выполняется через API EvoPlus.

При первой настройке виджеты выключены. Следующие запуски сохраняют выбранные настройки. В редакторе можно увидеть примеры целей без заданного значения. В игре такие цели скрыты.

Панель вкладок чата отображается при открытом чате. В категории **Интерфейс** выбирается горизонтальная или вертикальная ориентация. По умолчанию перетаскивание этой панели в открытом чате отключено, чтобы вкладки принимали клики; положение и масштаб меняются в общем редакторе EvoPlus.

## Статистика добычи

Категория **Шахта** содержит сброс статистики с подтверждением и секцию **Учитывать в счётчике**. Источники денег выбираются отдельными переключателями: блоки, бочки, руны, бомбы, питомцы, посохи и мультитул. Выбор действует одинаково на деньги в статистике добычи и в её целях. Счётчик подтверждённых блоков продолжает работать и при отключённом учёте денег от блоков.

Счётчик блоков использует локальное успешное разрушение и подтверждение сервера: в течение одной секунды сервер должен прислать обновление той же координаты до воздуха. Блок засчитывается сразу после подтверждения. Ошибочно предсказанные разрушения, которые сервер откатил, не учитываются. Общая статистика и активные цели используют один источник подтверждённых блоков. Деньги учитываются отдельно по распознанным сообщениям награды: сервер может объединять доход нескольких блоков. Подтверждение разрушения само по себе не доказывает выплату, поэтому блоки без прибыли также могут входить в счётчик.

Общая статистика сохраняется отдельно для каждого адреса сервера до ручного сброса, включая перезапуски игры. Темп добычи за час рассчитывается по недавней активности и снижается до нуля при простое. Активное время приостанавливается через пять секунд после последнего подтверждённого блока.

## Цели

**Цели Добычи** позволяют задать количество блоков, активное время, деньги и шарды. **Цели Клана** содержат цели по очкам, золоту и опыту клана.

Изменения значений применяются при закрытии настроек. Замена цели с незавершённым прогрессом требует подтверждения в окне EvoPlus. Ввод каждого символа не изменяет прогресс действующей цели; отмена подтверждения сохраняет прежнюю цель. Рядом с полем каждой из семи целей постоянно видна иконка сброса, в том числе при значении `0`. Подтверждение появляется сразу и показывает точные значения прогресса и статистики, которые будут обнулены. Отдельные дублирующие карточки сброса удалены. Общий сброс очищает прогресс, сохраняя значения целей; его подтверждение также показывает текущую статистику.

Поддерживаются числовые сокращения, например `5.32B` и `5.32K`. Максимум для денег и шардов — `999Q`, для клановых целей — `1M`, для блоков — `9 999 999`, для времени — `9999` минут. Недопустимые значения не принимаются. Блоки засчитываются после подтверждения разрушения сервером, а деньги добавляются отдельно по сообщениям о награде. После выполнения цель фиксирует достигнутые значения до сброса или замены.

Уведомления о выполнении целей показывает EvoPlus. Их можно включать отдельно для добычи и клана. Общая длительность от 1 до 60 секунд настраивается в категории **Интерфейс**. Прогресс сохраняется после переподключения и перезапуска игры.

## Цели рыбалки

В категории **Цели Рыбалки** раздел **Цель по уровню питомца** содержит измерение, редкость, текущий уровень, опыт на нём и целевой уровень. Оба уровня выбираются из списков: обычный мир — прокачка с 1 до 11, Ад — с 11 до 16, Энд — с 16 до 21. Целевой уровень всегда выше текущего. Опыт на текущем уровне в описании питомца. Кнопка **Поставить цель по уровню** берёт требование перехода на целевой уровень и вычитает уже набранный опыт питомца. Например, для легендарного питомца с 16-го на 20-й уровень требуется 1 638 400 опыта, при текущем опыте 100 000 — 1 538 400. Затраты на промежуточные переходы не суммируются. Уровни 16–20 повторяют адскую шкалу 11–15. Сохранённые цели по уровню пересчитываются по этой формуле при загрузке. В разделе **Цель по опыту** есть отдельный выбор измерения и поле необходимого опыта. Новая цель применяется только кнопкой. Изменение полей не меняет уже установленную цель.

Прогресс — текущий опыт рыбы в инвентаре, а не история уловов. Учитываются только рыба и ведро выбранного измерения: поштучный опыт 22 видов рыб из таблицы умножается на размер стопки, для обычного, адского и эндер вёдер читается накопленное значение из описания. Вместимость ведра не прибавляется. В общих настройках переключатель **Учитывать опыт в вёдрах** по умолчанию включён. При отключении остаётся только опыт рыбы. Изменение применяется при ближайшем пересчёте инвентаря и сохраняется в конфиге. Настройка действует для обоих типов целей. Поддерживаются русские названия предметов; интерфейс локализован на русский и английский.

Инвентарь пересчитывается каждые четыре клиентских тика, включая предмет на курсоре, а рюкзак не учитывается. Перекладывание, расход или выбрасывание рыбы уменьшает прогресс. При достижении цели уведомление показывается один раз. Уведомления можно отключить. Активная цель и отметка об уведомлении сохраняются отдельно для каждого сервера, а содержимое инвентаря заново читается при входе.

Новый виджет по умолчанию выключен. Для цели по уровню он содержит пять строк: редкость, измерение, целевой уровень полностью (например, «Цель: 21 уровень»), «Опыт» и остаток. Для цели по опыту остаются три строки: измерение, «Опыт» и остаток. Целевое количество видно после `/`.

## Боссы, киллы и клан

Для боссов доступны два виджета: деньги и шарды, а также обычные, адские и энд жетоны из сообщений о наградах за боссов и данжей. Категория **Боссы** содержит отдельные сбросы наград и жетонов с подтверждением.

Категория **Киллы** содержит сброс счётчика с подтверждением. Количество отображается в виджете с алмазным мечом. Сброс киллов сохраняет остальные награды; деньги за киллы не добавляются к наградам боссов.

Клановый виджет показывает очки, опыт и золото клана. Категория **Клан** содержит сброс этой статистики с подтверждением.

Для денег используются сокращения K, M, B, T, Q с точностью до двух знаков после запятой; остальные награды отображаются целыми числами. Статистика наград и киллов хранится отдельно для каждого сервера и сохраняется до ручного сброса.

## Сохранение и разработка

Fabric ID мода — `evoassist`. Настройки продолжают храниться в `config/evoassist.jsonc`: элементы EvoPlus связаны с существующими значениями через `Setting.bind`, поэтому отдельный перенос целей и выбранных источников дохода не требуется. Видимость и геометрию виджетов сохраняет EvoPlus в конфиге аддона.

Файлы статистики:

- `config/evoassist_mining.properties` — общая статистика добычи по серверам;
- `config/evoassist_mining_goals.properties` — цели по блокам и времени;
- `config/evoassist_additional_goals.properties` — денежные, шардовые и клановые цели;
- `config/evoassist_fishing_goals.properties` — активные цели рыбалки и одноразовые уведомления по серверам;
- `config/evoassist_rewards.properties` — награды боссов, клановая статистика и киллы по серверам.

Интеграция использует `compileOnly` [EvoPlus API 1.9.0](https://github.com/evo-plus/evo-plus-api/tree/1.9.0); API предоставляет установленный EvoPlus. Минимальная версия EvoPlus 3.3.4 записывается в `fabric.mod.json`. Версии зависимостей задаются в `gradle.properties`; `runClient` подключает EvoPlus и Fabric Language Kotlin для разработки.

`gradlew build` проверяет распознавание и сохранение наград, киллы, цели, локализацию, геометрию вкладок чата, регистрацию нативных настроек и виджетов, сохранение видимости при обновлении, подтверждение разрушений блоков сервером и безопасное редактирование целей.
