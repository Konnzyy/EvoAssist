# EvoAssist для Minecraft 26.2

Клиентский Fabric-мод для DiamondWorld Prison Evo.

## Требования

- Minecraft 26.2
- Fabric Loader 0.19.5 или новее
- Fabric API для Minecraft 26.2
- Java 25

## Установка

Скопируйте `EvoAssist-v1.0.2+mc26.2.jar` и Fabric API в папку `mods` вашей игры. Запустите Minecraft с профилем Fabric 26.2.

Нажмите **правый Ctrl**, чтобы открыть настройки, либо используйте **/ea**. Другую клавишу для открытия меню можно назначить во вкладке Интерфейс > Настройки меню, используя такую же систему привязки клавиш, как в настройках управления Minecraft. Доступные вкладки: Автокликер, Боссы, Шахта, Цели Добычи, Клан, Цели Клана и Интерфейс. Русский и английский языки автоматически выбираются в зависимости от языка Minecraft, а для остальных языков используется английский.

Автокликер запускается назначенной клавишей во время игры и останавливается при открытии любого экрана. Режим Нажатие выполняет повторяющиеся клики с выбранным значением CPS, а режим Зажатие удерживает кнопку мыши до повторного нажатия назначенной клавиши. Команды: `/evoassist` или `/ea` для открытия настроек, а команды `/evoassistwidgets` или `/eaw` для открытия редактора виджетов.

Кнопка с плюсом рядом с названием мода открывает редактор всех виджетов. Если мир уже загружен, редактор оставляет игровую сцену чёткой и не затемняет её, благодаря чему видимые виджеты других модов можно использовать как ориентиры для расположения. Во время обычной игры виджеты не имеют фона, а в редакторе фон показывает их кликабельные границы.

Цели Добычи позволяет отдельно задавать цели по количеству блоков, активному времени, деньгам и шардам. Цели Клана содержит отдельные цели по очкам, золоту и опыту клана. После выполнения цель фиксируется до её сброса или замены. Для числовых целей поддерживаются десятичные сокращения, например `5.32B` или `5.32K`. Максимальное значение для денег и шардов составляет `999Q`, для клановых целей — `1M`, а для времени — 9999 минут. Эти ограничения применяются автоматически и не отображаются в подсказках полей ввода. Продолжительность уведомления о выполнении цели является общей для всех типов целей и может быть настроена от 1 до 60 секунд. Статистика целей и позиции виджетов сохраняются после переподключения и перезапуска игры.

Общая статистика добычи сохраняется отдельно для каждого сервера и остаётся после переподключения и перезапуска игры, пока вы вручную не сбросите её в меню мода. Расчёт добычи в час основывается на недавней активности и постепенно снижается до нуля, если вы перестаёте добывать блоки.

Вкладка Боссы содержит два виджета: первый для отображения денег, шардов, второй для отображения жетонов разных измирений полученных из сообщений о наградах за боссов и данжей. Вкладка Клан содержит один виджет для очков, опыта и золота клана. В каждой вкладке есть переключатель отображения, отдельная кнопка сброса статистики и кнопка для изменения положения и масштаба соответствующего виджета.

Для отображения денег используются сокращения K, M, B, T и Q с точностью до двух знаков после запятой. Остальные награды отображаются целыми числами. Награды сразу сохраняются в `config/evoassist_rewards.properties` отдельно для каждого адреса сервера и сохраняются после переподключения и перезапуска игры до ручного сброса.

Fabric ID мода — `evoassist`. Конфигурация сохраняется в `config/evoassist.jsonc`, а цели добычи — в `config/evoassist_mining_goals.properties`. Изменение ID означает, что мод начинает работу с новыми настройками и статистикой вместо загрузки файлов, ранее созданных под ID `evo_assist`.
